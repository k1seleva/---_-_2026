# Как сообщать пациенту рекомендации через push

Разбор для прототипа «Маршрут пациента». Тексты лежат в `seed_demo.PUSH_TEXT` (push) и `TEMPLATES_TEXT`
(личный кабинет), подстановка врача и времени в `apps/patients/services/push.py`.

## Что видит пациент

Экран блокировки, уведомление свернуто:

```
СМ-КЛИНИКА                                         сейчас
Результат исследования готов
Рекомендуется консультация профильного специалиста.
Ближайшее время: врач Иванова Е. А., 14 октября в 10:30,
клиника ВДНХ.
                                            Выбрать время
```

После входа в кабинет то же сообщение раскрывается полностью: специальность («консультация гинеколога»),
понятное объяснение находки, кнопки «Записаться», «Выбрать другое время», «Уже был у врача».

## Правила текста и почему так

| Правило | Почему |
|---|---|
| На экране блокировки нет диагноза, находки и специальности врача | Экран видят посторонние. Сведения о здоровье составляют врачебную тайну. Даже «онколог» или «маммолог» на экране раскрывает больше, чем нужно |
| Нейтральная формулировка: «Рекомендуется консультация профильного специалиста» | Не пугает и не ставит диагноз, но ясно говорит, что нужно действие |
| Конкретный следующий шаг: врач, дата, время, клиника | Абстрактное «запишитесь к врачу» откладывают. Готовое предложение принимают одним нажатием |
| Одна кнопка действия | Две и больше кнопок на свернутом push не видны, выбор тормозит решение |
| Заголовок до 40 знаков, текст до 130 | Столько показывает свернутое уведомление на iOS и Android, остальное обрезается |
| Ссылка ведёт на запись после входа в кабинет | Подробности и запись только у самого пациента. Push может прочитать кто угодно, кабинет нет |
| Без «срочно», восклицательных знаков и сроков в днях | Тревожный тон снижает доверие. Экстренные находки идут не через push, а звонком персонала |
| С 21:00 до 9:00 push не уходят, не больше трёх сообщений в сутки | Ночной push воспринимают как спам и отключают уведомления совсем |
| Повтор не чаще раза в сутки, затем SMS (60+) и звонок координатора | Лестница каналов настроена в политике эскалации, выбор каналов за пациентом |
| Нет свободного времени: строка о враче просто не выводится | Текст остаётся корректным, без пустых мест («врач , в »), это проверяет тест |

## Последовательность сообщений по одной рекомендации

1. Результат готов: нейтральный текст и ближайшее время у врача.
2. Через 24 часа без записи: «Консультация ещё не назначена» и снова ближайшее время (оно могло измениться).
3. Через 72 часа: «Рекомендация врача ждёт вас», без врача, с выбором очно или онлайн.
4. Дальше push не повторяется: задача координатору позвонить.

## Варианты текста для A/B-теста

Разбор с позиции маркетолога и варианты для каждого сценария (результат готов, дообследование, контроль через
N месяцев, напоминания): Claude Doc «Push о дообследовании: варианты текста»
(https://claude.ai/code/artifact/eca25e44-2d37-4295-bb95-874df60ed6f5). Рекомендуемый вариант B «Готовый шаг»:

```
Анна, врач рекомендует консультацию
По итогам исследования. Ближайшее время: Иванова Е. А., завтра в 10:30, ВДНХ. Запись в одно нажатие
```

Победителя выбирают по доле записавшихся за 72 часа; рост отключений уведомлений отменяет победу.

## Что дальше в пилоте

- Проверить на фокус-группе два варианта: с именем врача и без него. Гипотеза: с именем записываются чаще.
- Дать пациенту настройку «Скрывать текст на экране блокировки» (только «Новое сообщение в кабинете»).
- Учитывать любимого врача и клинику пациента при выборе ближайшего времени.
